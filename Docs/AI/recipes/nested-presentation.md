# Рецепт: вложенная presentation-иерархия

Использовать для списка, item, вложенной страницы, дочернего gameplay-объекта или дерева UI.

## Выбор узла

| Ситуация | Решение |
| --- | --- |
| Независимый режим, feature, сцена или отдельные ресурсы | Child root |
| Собственное presentation-state, подписки, команды или async | Дочерняя MVP/MVVM-семья, которой владеет parent Presenter/ViewModel |
| Только визуальная часть и Unity-ссылки | Child View/MonoBehaviour внутри семьи родителя, без отдельной логики |
| Простое поле/кнопка без состояния | Остаётся частью parent View |

## Порядок

1. Root/factory создаёт семью верхнего уровня. Parent Presenter/ViewModel создаёт дочернюю семью с явными зависимостями: получает или создаёт child View, затем создаёт её Model и Presenter/ViewModel.
2. Parent выбирает единственный механизм владения: terminal `CompositeDisposable` только для child с тем же lifetime; явная коллекция/поле для заменяемого child.
3. Parent вызывает один путь инициализации: sync или async.
4. View привязывается к созданному Presenter/ViewModel и только отображает его состояние; она не создаёт presentation-объекты.
5. Parent явно освобождает child при удалении item, закрытии страницы или собственном `Dispose`.

## Список

- Parent хранит children по стабильному domain-id, а не по позиции в списке.
- При обновлении списка parent сопоставляет данные с существующими children, создаёт отсутствующие и освобождает удалённые.
- Item сообщает действие наружу через command/callback; он не обращается к parent/sibling и не изменяет общую коллекцию напрямую.

## Страницы и окна

- Контейнер экрана владеет активной страницей.
- При навигации заранее определить policy: `dispose on close` или `parent-owned cache`.
- Cache не является глобальным сервисом и не меняет owner: его владельцем остаётся контейнер экрана.
- Активную/заменяемую страницу не добавлять навсегда в `CompositeDisposable`; при смене явно освободить старую и заменить ссылку.

## Запрещено

- Создавать DI-container на item/page.
- Создавать child из Unity View.
- Передавать parent как скрытый service locator.
- Добавлять child в двух владельцев.
