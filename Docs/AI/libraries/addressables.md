# Addressables и сгенерированные ключи

Источник истины — Addressables Settings. Генератор ключей будет добавлен отдельной задачей; после его появления он станет обязательным путём получения runtime-key.

Сгенерированные `.cs` файлы не редактируются вручную. До появления генератора новый runtime-код с Addressables не писать.
