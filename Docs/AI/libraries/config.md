# Config

Использовать `Config` для типизированных страниц конфигурации (`IConfigPage`). Загрузка выполняется в bootstrap до запуска game flow.

`DependencyAwareConfigParser` используется, когда страница действительно зависит от другой страницы; независимые данные не связываются искусственно. В Unity-потоке не выполнять синхронный тяжёлый парсинг.

Получение страницы — через `IConfig.GetConfigPage<T>()` внутри composition/use case после успешной инициализации. Не читать конфиг статически и не изменять страницу во время игры.
